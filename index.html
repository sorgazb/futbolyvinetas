Fútbol y Viñetas

Historias de fútbol contadas en viñetas, en vídeos cortos para YouTube, TikTok e Instagram.

Política de privacidad

"Futbol y Vinetas Stats" es una herramienta interna que usa el propio titular del canal para recibir un resumen diario de sus estadísticas.

  • Solo pide permisos de lectura de YouTube (YouTube Data API y YouTube Analytics API) sobre el canal propio.
  • No accede a datos de otras personas ni de otros canales.
  • Los datos solo se usan para enviar ese resumen al titular por Telegram. No se venden, no se comparten con terceros y no se usan para publicidad.
  • El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Condiciones de uso

"Futbol y Vinetas Stats" es una herramienta privada sin ánimo de lucro, de uso exclusivo del titular de las cuentas de Fútbol y Viñetas.

  • No está abierta al público ni admite registros de terceros.
  • Solo lee estadísticas de las cuentas propias (YouTube, TikTok e Instagram) con permisos de lectura. No publica, no modifica ni borra contenido.
  • Se ofrece tal cual, sin garantías. Su uso implica aceptar también las condiciones de cada plataforma.
